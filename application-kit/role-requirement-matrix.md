# Functional analyst requirements

| Requirement | Evidence | Demo | Validation boundary |
|---|---|---|---|
| Requirements discovery | fictional interviews and workshop plan | event board | actual stakeholder interviews not performed |
| Functional specifications | rules, stories, state model | checker | business assumptions need owner approval |
| Technical collaboration | interface contracts and refinement examples | delayed EDI | real team/partner refinement not performed |
| Quality | executable rules, UAT plan | T-30 boundary | transaction/concurrency/UAT planned |
| Delivery and support | release plan, KB, separate delivery status | failed-notification explanation | no production rollout or measured result |
