# Two-minute demo

Start: this is an independent fictional portfolio case. The checker is a decision illustration, not a production booking system.

| Time | Action | Explain |
|---|---|---|
| 0:00–0:20 | Open the site and checker | Four channels need the same business rules. |
| 0:20–0:40 | Choose on-time preset | Automatic acceptance, rules listed. |
| 0:40–1:00 | Choose late preset | Gated-in trailer requires terminal approval. |
| 1:00–1:20 | Choose Exactly T-30 | Rejected LOADING_CLOSED. A pending approval expires at this same boundary. |
| 1:20–1:45 | Choose Delayed EDI at closure | Timely receipt does not permit execution after closure. |
| 1:45–2:00 | Open review decisions | Applied means committed booking. Notification delivery has a separate status. |

Offline fallback: use the deck and one-pager. Show the 20:20 receipt / 21:30 processing example verbally. Do not depend on a live terminal or claim actual stakeholder sign-off.
